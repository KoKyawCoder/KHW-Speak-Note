\# KHW Speak Note – NVDA Add-on for Blind Students



KHW Speak Note is an NVDA add-on designed to help blind students, especially students who study mathematics.



When solving long mathematical calculations, it is easy to forget previous steps while continuing the solution. Normally, you may need to move the arrow keys back and forth repeatedly to review forgotten steps and return to your current position. This can interrupt your workflow and make calculations slower and more difficult.



As a blind student from Myanmar, I personally faced this problem while studying mathematics. That is why I developed this add-on.



\## Features



\* Save important calculation steps instantly

\* Store unlimited notes and math steps

\* Quickly review saved steps anytime

\* Navigate between saved notes easily

\* View all saved notes in a list

\* Clear saved notes when needed

\* Useful not only for mathematics, but also for general note-taking



\## Keyboard Shortcuts



| Shortcut           | Function                                  |

| ------------------ | ----------------------------------------- |

| `Ctrl + Shift + M` | Save the current calculation step or note |

| `Ctrl + Shift + R` | Read saved calculation steps              |

| `Ctrl + Shift + H` | Open the saved notes list                 |

| `Ctrl + Shift + 2` | Move to the previous saved step           |

| `Ctrl + Shift + 3` | Move to the next saved step               |



\## How It Helps



With this add-on, you can focus on solving problems without worrying about forgetting previous steps. It is especially useful for:



\* Long mathematics calculations

\* Algebra and equation solving

\* Study notes

\* Quick reminders

\* General text notes
