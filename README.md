# KHW Speak Note

**KHW Speak Note** is a free and accessible NVDA add-on designed to help blind students save, review, and navigate important information while studying, especially during long mathematical calculations.

## Why KHW Speak Note?

When solving mathematics problems, blind students often need to remember previous calculation steps while continuing their work. Using arrow keys to repeatedly move back and forth through a document can interrupt concentration and slow down the problem-solving process.

As a blind student from Myanmar, I personally experienced this challenge while studying mathematics. To solve this problem, I created KHW Speak Note.

This add-on allows you to instantly save important calculation steps, formulas, notes, or reminders and access them whenever needed without losing your current position.

## Features

* Save important calculation steps instantly
* Store unlimited notes and mathematical working steps
* Review saved notes at any time
* Quickly move between saved items
* Browse all saved notes in a convenient list
* Delete individual notes or clear all saved notes
* Useful for mathematics, education, study sessions, and general note-taking
* Designed specifically for blind users and NVDA screen reader users

## Keyboard Shortcuts

| Shortcut         | Function                                  |
| ---------------- | ----------------------------------------- |
| Ctrl + Shift + M | Save the current calculation step or note |
| Ctrl + Shift + R | Read saved calculation steps              |
| Ctrl + Shift + H | Open the saved notes list                 |
| Ctrl + Shift + 2 | Move to the previous saved step           |
| Ctrl + Shift + 3 | Move to the next saved step               |

## Use Cases

KHW Speak Note can be helpful for:

* Long mathematical calculations
* Algebra and equation solving
* Geometry and trigonometry exercises
* Study notes and revision materials
* Remembering formulas and important information
* Quick reminders during work or study
* General note-taking for NVDA users

This add-on is especially useful for:

* Blind students
* NVDA screen reader users
* Mathematics learners
* Teachers and accessibility professionals
* Anyone who needs quick note-taking within NVDA

## Accessibility

KHW Speak Note is built with accessibility as its primary goal. The add-on integrates directly with NVDA and provides a simple keyboard-driven experience that works efficiently with screen readers.
